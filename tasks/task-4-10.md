## Description
Ensure modal styling is responsive and works on all screen sizes:
- Mobile: Full-screen or near-full modal
- Tablet: Larger modal with padding
- Desktop: Centered modal with max-width
- Scrollable content on small screens
- Touch-friendly on mobile

## Definition of Done
- [ ] Modal works on mobile (320px+)
- [ ] Modal content is scrollable on small screens
- [ ] Modal takes appropriate width on each screen size
- [ ] Content is readable on all sizes
- [ ] Close button is accessible on mobile
- [ ] No content overflow/cut off
- [ ] Padding and margins are appropriate
- [ ] Text sizes are readable on mobile

## Implementation Notes
- Use Bootstrap responsive utilities
- Use media queries for custom breakpoints
- Test on actual mobile devices
- Consider full-screen modal on mobile
- Ensure close button is at top
